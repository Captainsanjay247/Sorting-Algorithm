# Sorting Algorithm Visualizer

**Mini Project | B.Tech Information Technology**

An interactive web-based Sorting Algorithm Visualizer developed using HTML, CSS, and JavaScript. The project helps users understand how different sorting algorithms work through real-time visualization and performance analysis.

## Features

- Real-time sorting visualization
- Supports 9 sorting algorithms
- Adjustable array size and sorting speed
- Custom array input
- Pause, Resume and Reset functionality
- Comparison and swap/operation tracking
- Algorithm complexity analysis
- Performance visualization
- Responsive user interface

## Sorting Algorithms

- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort
- Heap Sort
- Shell Sort
- Counting Sort
- Radix Sort

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Data Structures & Algorithms

## Project Objective

The main objective of this project is to visually demonstrate the working of sorting algorithms and make their execution, performance, and complexity easier to understand.

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

## Project Structure

- `index.html` – Website structure
- `style.css` – Styling and responsive design
- `script.js` – Sorting algorithms and project functionality
