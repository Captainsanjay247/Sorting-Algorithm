Quick Sort

Quick Sort is a divide-and-conquer algorithm that selects a pivot element and partitions the array into two subarrays, then recursively sorts the subarrays.

Best Case O(n log n)
Average Case O(n log n)
Worst Case O(n²)
Space Complexity O(log n)
Stable No
In-place Yes
